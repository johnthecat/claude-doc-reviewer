      How this review works

      The rules

      • Claude goes through the document one block at a time: a paragraph with the lists, tables and code that follow it. The block under review has an amber bar, and its card next to it holds Claude's questions.
      • Approved blocks have a green bar. They stay as they are unless you confirm a change to them.
      • Every other block is a draft. After each change Claude brings the drafts in line with the approved blocks and with the change.
      • A change that touches an approved block is held back, whole, under that block. Write how to resolve it if you like, then choose Update to let Claude change the approved block, or Drop.
      • Claude takes your requests one at a time, in the order you sent them.
      • The review is done when every block is approved or when you finish it.

      Using the page

      • Click a block to move the review there. Clicking a word also selects it.
      • Select text and press Comment to ask for a change. ⌘ ↵ sends it and Esc cancels. Once Claude makes the change, the review moves to that block if it is open.
      • Ask a question in a comment the same way. Claude answers it on the comment and changes nothing.
      • Answer a question in its field. ↵ sends the answer and ⇧ ↵ adds a line.
      • Approve (A) approves the block and moves to the next open one. Skip (J) moves on without approving.
      • The Claude button in the header shows what Claude is doing and lists the requests still waiting.
      • Activity lists past comments, answers and edits.
      • You can edit the file in your own editor too. The page follows it, and Claude checks the drafts against your edit.
      • Finish review asks Claude for a summary and ends the review. Exit stops the server and hands control back to Claude. Your progress is saved, and opening the review again resumes it. Answers and comments you typed but did not send are kept in this browser until the review finishes.
